GETTING STARTED

Start playing with your own cards.

From preparing a game setup to registering your cards. Choose how to start based on what you have.

What you see may differ depending on your device, OS and game setup.

The screens use demo cards. What you actually use are your own card images or a card ZIP you received. Substitute your own game name, card names and counts as you go. You do not need the demo data.

1. Choose your starting point

What you haveHow to start
A custom QR code or share code from someoneImport shared game
You know the zones and deck size you needCreate with guided setup
You want to work out the setup by talking it throughCreate with AI

You only need one of the three. After that, register images or a card ZIP.

2A. Use someone's QR code

  1. In "Game setup", open "Import shared game".
  2. Scan a QR code shown on another device with the camera. If the image is saved on the same phone, choose it with "Read QR from image".
  3. If you have a share code or link, paste it into the field.
  4. After importing, open the game and check that the board and deck size match what you want to play.
A QR code carries a game setup. Card images and finished decks are prepared separately.

To share your own game setup, tap "Share" on that game in the "Game setup" list. Have the other person scan the QR code on screen, or send it with "Share as image" or "Share link". Attributes, rules and board design are shared; card images are not included. If the setup is too large for a QR code, use the link or code.

2B. Create with guided setup

Open "Game setup" → "Create with guided setup" and answer the questions. You do not need to match the numbers in the examples.

What you decideDemo exampleIn your game
Game nameDemoCardGameA name that is easy to tell apart
ZonesDeck, hand, field, life, discardChoose the zones you use
Field slots5 slotsAs many as you want to line up
Shared zoneOne fieldAdd only if needed
Card attributesColor, type, cost, powerWhat you want to track. You can add these later
Deck structureMain deck of 30 cards, placed in the deck zoneDecide the count and where each pile starts

In the app, the zones are listed as "Deck area", "Character area", "Life / Shield area", "Discard area" and "Hand area". Choose the ones you use and rename them on the spot. The demo renames them to "Deck", "Field", "Discard" and so on. Along the way you can also choose whether to count life as a number (Counting life).

Check the layout and save. You can add or edit quick actions later. Make sure to check where each pile starts, since that is where its cards are placed when a game begins.

2C. Create with AI

  1. Open "Game setup" → "Create with AI".
  2. Copy the discussion prompt and paste it into a chat with the AI you use.
  3. Talk through the zones, attributes, and the deck's piles and counts. The AI is already told the basic shapes, such as the deck (one slot, cards stacked without offset) and the hand (one slot, cards side by side, overlapping when they do not fit), so you only need to discuss what you want to change for your game.
  4. Once you have decided, copy the TCG-T format instructions and paste them into the same chat.
  5. Paste the setup data the AI returns into TCG-T and validate it.
  6. Fix any errors, check the content and layout, and create the game.
This is a conversation with an outside AI. It is a different feature from the in-app image autofill, and the outside AI's own terms of service apply.

3A. Register images from your device or cloud

  1. In "Cards", choose the game to add to and tap "+ Add".
  2. Pick photos from "Camera roll", or files on your device or in the cloud from "File". If you only have a share link to an image, save it to your device or a storage location you can open first.
  3. Crop as needed. If one image contains several cards, use the cut-out or grid split.
  4. Check the card name and the attributes you need in the draft, then save. A set number is optional when registering from images.

Tap an image to enlarge it. The screens are demos for explanation.

Image autofill is optional. If you use it, check the points shown on screen, review the result, then save. You can also enter everything by hand.

Alternate art of the same card

When you register a card with the same set number as an existing one, or with no set number and the same name, you are asked what to do. Choose "Add as alternate art" to keep it as one card with an extra image (the attributes you entered are not used). To make it a separate card, choose "Save as a separate card". When importing in bulk, you can choose "Alt art", "Separate" or "Skip" for each draft row.

You can also add images from "Alternate art" on the edit screen of a registered card, and choose which image to show there. Cards with alternate art get a badge such as "+1" in the list.

3B. Register a card ZIP someone made

  1. Get a card ZIP in TCG-T format and save it to your device or a cloud location you can open.
  2. In the game you are adding to, open "+ Add" → "Choose a ZIP". On Android, you can also pick a folder where the ZIP was extracted with "Choose a folder (unzipped)".
  3. Check the game name, count and any warnings. To add to a game you already made, choose the selected game.
  4. Check how missing attributes and duplicate set numbers are handled, import, and save the drafts.

Tap an image to enlarge it. The screens are demos for explanation.

A card ZIP is not just a ZIP of images. It does not include the board, quick actions or finished decks. If you import it as a new game, set up the board and decks separately.

4. Once your cards are in

Check that images and names show up in the card list. From here, the steps are the same however you registered your cards.

Tap an image to enlarge it. The screens are demos for explanation.

What you want to doHow
SearchType a name, set number or attribute value into the search box at the top.
Filter and sortOpen "Filter & sort". Filter by choice or number attributes, and sort by name, set number or attribute.
Act on several cardsTap "Select" or long-press a card to select several. You can move them to another game with "Change game", or delete them.
View or fix a cardTap a card to open the enlarged image and attributes, where you can edit or delete it.

Cards deleted in bulk cannot be restored. If they were in a deck, they are also removed from that deck.
