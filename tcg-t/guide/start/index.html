入門編

自分のカードで、遊び始める。

ゲーム設定を用意して、カードを登録するまで。手元にあるものに合わせて、始め方を選べます。

更新：2026年9月27日 · 画面例：iOS版 1.0.0の開発ビルド
端末・OS・ゲーム設定により、表示や配置が異なる場合があります。

画面例にはデモカードを使っています。実際に使うのは、ご自身のカード画像や受け取ったカードZIPです。ゲーム名・カード名・枚数を読み替えて進めてください。デモデータの入手は不要です。

1. 自分に合う入口を選ぶ

用意できるもの選ぶ方法
人が作ったカスタムQR・共有コード共有から取り込む
使う置き場所やデッキ枚数がわかるかんたん設定で作る
設定内容を相談しながら決めたいAIと相談して作る

3つの方法のうち、1つを選べば大丈夫です。その後、画像またはカードZIPを登録します。

2A. 人のカスタムQRを使う

  1. 「ゲーム設定」から「共有から取り込む」を開きます。
  2. 別の端末のQRをカメラで読み取ります。同じスマホに保存した画像は「画像からQRを読み取り」で選べます。
  3. 共有コード・リンクがある場合は、貼り付け欄を使います。
  4. 取り込み後、ゲームを開き、盤面やデッキの枚数が遊びたいものと合っているか確認します。
QRで受け取るのはゲーム設定です。カード画像や組み上がったデッキは別に用意します。

2B. かんたん設定で作る

「ゲーム設定」→「かんたん設定で作る」を開き、質問に答えます。画面例の数値に合わせる必要はありません。

決めることデモの例自分のゲームでは
ゲーム名DemoCardGame区別しやすい名前
置き場所山札・手札・場・ライフ・捨て札使う置き場所を選ぶ
場の枠5枠並べたい数にする
共通ゾーンフィールド1つ必要な場合だけ追加
カード属性色・種類・コスト・パワー管理したい項目。後からでも可
デッキ構成メイン30枚、山札へ配置枚数と初期配置先を決める

配置を確認して保存します。クイック操作の追加編集は後からでもできます。各山の初期配置先は、開始時にカードを置く場所なので確認しておきましょう。

2C. AIと相談して作る

  1. 「ゲーム設定」→「AIと相談して作る」を開きます。
  2. 討議用プロンプトをコピーし、自分が使っているAIの会話に貼り付けます。
  3. 置き場所・属性・デッキの山と枚数を相談します。
  4. 内容が決まったらTCG-Tの形式指示書をコピーし、同じAIの会話へ貼ります。
  5. 返ってきた設定データをTCG-Tへ貼り付けて検証します。
  6. エラーを直し、内容と配置を確認して作成します。
これは外部AIとの相談です。画像を読み取るアプリ内のAI自動入力とは別の機能で、外部AIには各サービスの利用条件が適用されます。

3A. 手元・クラウドの画像を登録

  1. 「カード一覧」で登録先のゲームを選び、「＋ 追加」を押します。
  2. 写真は「カメラロール」、端末やクラウドのファイルは「ファイル」から選びます。共有リンクしかない画像は、先に自分の端末や開ける保存先へ保存します。
  3. 必要に応じて切り抜きます。1枚の画像に複数のカードがある場合は、切り出しや格子分割を使います。
  4. 下書きでカード名・必要な属性を確認して保存します。型番は画像登録では任意です。

画像をタップすると拡大できます。画面は説明用のデモです。

AI自動入力は任意です。使う場合は画面のポイント条件を確認し、結果を見直して保存します。手入力でも登録できます。

3B. 人が作ったカードZIPを登録

  1. TCG-T形式のカードZIPを受け取り、端末または開けるクラウドへ保存します。
  2. 登録先のゲームで「＋ 追加」→「ZIP を選ぶ」を開きます。
  3. ゲーム名・件数・警告を確認し、作成済みのゲームに入れるなら「選択中のゲーム」を選びます。
  4. 不足する属性や同じ型番の扱いを確認して取り込み、下書きを保存します。

画像をタップすると拡大できます。画面は説明用のデモです。

画像を圧縮しただけのZIPとは異なります。カードZIPに盤面・クイック操作・完成済みデッキは含まれません。新しいゲームとして取り込んだ場合は、盤面とデッキを別に設定してください。

4. カードが揃ったら

カード一覧で画像と名前が表示されることを確認します。ここからは、どの方法で登録しても同じ手順です。

画像をタップすると拡大できます。画面は説明用のデモです。
