Updates

Changes in upcoming and released versions, and confirmed issues.

1.0.3 (coming soon)

  • "Suspended games" and "Game history" are now together in "Solo Play records". Choose whether to save when you exit; the latest game is kept automatically. Save up to 10 records for free or 100 with Premium. Find them by tags or results, continue, replay, or branch. You can also replay online match records.
  • Edit deck names and deck tags directly in the deck list and filter by tag. Active sleeves appear behind deck covers.
  • After creating an online table, use "Send an invite" to share the room code and store links.
  • Fixed a crash after editing and saving from deck details, a board shrinking when a game has shared zones, and a Solo Play record sometimes missing immediately after an app crash.
Available now

1.0.2

Released on iOS and Android on November 4, 2026.

  • When you close the first-run guide, a generic "Sample" game is now set up for you, so you can start by adding cards without creating a game first.
  • Fixed an issue where typing a zone name in Japanese in the board settings could commit text in the middle of conversion.

1.0.1 (first release)

Released on iOS and Android on October 31, 2026. Future changes and confirmed issues will be posted on this page.
