# プライバシーポリシー

最終更新: 2026-09-25

本ポリシーは、モバイルアプリ「TCG-T」（以下「本アプリ」）における個人情報等の取り扱いを定めるものです。

---

## 1. まとめ

- **アカウント登録は不要です。** ログインせずに使っている間は、氏名・メールアドレス・電話番号を取得しません。
- **Apple または Google でログインした場合に限り、そのアカウントのメールアドレス（Apple の「メールを非公開」を選んだ場合は Apple が発行する中継用アドレス）と識別子を受け取ります。** ポイント残高と装飾の権利を機種変更後も引き継ぐためだけに使います。
- **登録したカード・デッキ・ゲーム設定・画像は、原則として端末の中だけに保存されます。**
- サーバーへ送るのは、**AIによる自動入力を使ったときの画像**、**オンライン対戦で使うデッキのカード（対戦中だけ）**、**ポイント残高・購入や広告視聴の記録**、**ログインした場合のアカウント情報**、**任意の利用状況**だけです。
- 広告（Google AdMob）を表示します。広告のための識別子の利用は、端末の設定と同意画面で拒否できます。

## 2. 取得する情報と目的

### 2-1. 端末内だけに保存されるもの（送信しません）

| 情報 | 例 |
|---|---|
| ゲーム設定 | 属性・デッキ構成・盤面デザイン・ルール |
| カード情報 | カード名・型番・属性・**カード画像** |
| デッキ | 構成、代表カード、スリーブなどの装飾設定 |
| 進行中／中断中の一人回しの状態 | 盤面の配置、ターン数 |
| アプリの設定 | 表示言語、テーマ、表示列数 |

これらは端末のアプリ領域（アプリ内ストレージおよびファイル領域）に保存されます。
**アプリを削除すると、これらは端末から削除されます。**

### 2-2. サーバーへ送信するもの

| 情報 | 送信先 | 目的 | 備考 |
|---|---|---|---|
| 匿名アカウントの識別子（ランダムなID） | 当方のサーバー（Supabase） | ポイント残高と装飾の権利をユーザーごとに管理するため | 氏名等とは結び付きません |
| **ログインした場合**のメールアドレスとログイン方法の識別子（Apple / Google） | 当方のサーバー（Supabase） | 機種変更や再インストールのあとも、同じポイント残高と装飾の権利を引き継ぐため | ログインは任意です。氏名は保存しません |
| ポイントの増減履歴 | 当方のサーバー | 残高の算定、二重付与・不正利用の防止 | 増減値・理由・日時 |
| AI機能の利用記録 | 当方のサーバー | 利用回数の上限（レート制限）の判定、運営費用の把握 | 日時・処理量（画像や結果の内容は含みません） |
| **カード画像** | 当方のサーバーを経由して Anthropic | カード名・型番・属性の自動入力（ユーザーが実行したときのみ） | 当方のサーバーでは保存しません |
| 装飾（スリーブ・プレイマット）の権利と有効期限 | 当方のサーバー | 交換した権利の記録 | 画像そのものは送信しません |
| **オンライン対戦**で使うデッキのカード（カード名・属性・カード画像） | 当方のサーバー（Supabase） | 対戦相手の画面にカードを表示するため | 対戦相手だけが見られます。卓を閉じたとき、または卓の期限（最長3時間）が過ぎたあとに自動で削除します |
| 購入の記録（購入した商品・日時） | RevenueCat | アプリ内課金の確認と、ポイント・プレミアムの付与 | 支払い情報（カード番号など）は受け取りません |
| 広告識別子・端末情報・おおよその所在地（IPに基づく） | Google | 広告の配信と測定 | 下記 3 を参照 |
| 利用状況（画面の表示、機能の実行回数など） | PostHog | 不具合の把握と改善 | 設定でオフにできます |

**AI機能は、ユーザーが「AIで自動入力」を実行したときにだけ画像を送信します。**
アプリが自動的に画像を送信することはありません。

## 3. 広告について

本アプリは Google AdMob による広告を表示します（有料プランのご利用中は表示しません）。

- 広告の配信・測定のために、**広告識別子（iOS の IDFA / Android の広告ID）や端末情報、IPアドレスに基づくおおよその所在地**が Google に送信されることがあります。
- **iOS では、初回起動時に「トラッキングの許可」を確認します。** 拒否した場合、識別子は利用されません（広告は表示されますが、内容が利用者に合わせて選ばれなくなります）。
- **欧州経済領域・英国では、広告のためのデータ利用について同意を確認します。** 同意しない場合、そのための利用は行いません。同意の内容は、アプリの「設定 → 広告 → 広告のプライバシー設定」からいつでも変更できます。
- 動画広告を最後まで視聴するとポイントを付与します。この判定は Google からの通知に基づいて当方のサーバーで行います。

Google によるデータの取り扱いについては、Google のポリシーをご確認ください。

## 4. 第三者への提供・委託

以下のサービスを利用しています。目的の範囲を超えた提供は行いません。

| 事業者 | 用途 |
|---|---|
| Supabase | アカウント（匿名／ログイン）、ポイント台帳、オンライン対戦、サーバー処理の実行基盤 |
| Anthropic | カード画像からの属性抽出（AI） |
| Google（AdMob） | 広告の配信・測定、同意管理 |
| PostHog | 利用状況の分析 |
| Apple / Google（アプリストア） | 課金の処理 |
| Apple / Google（ログイン） | ログインを選んだ場合の本人確認 |
| RevenueCat | アプリ内課金の購入確認 |

各事業者のサーバーは日本国外に所在する場合があります。

## 5. 保存期間

- 端末内のデータは、利用者が削除するかアプリを削除するまで保持されます。
- サーバー上のポイント台帳・装飾の権利は、**残高や権利の正しさを保つため、アカウントの削除まで保持します**。
- AI機能の利用記録は、レート制限の判定に必要な期間を過ぎたものから順次不要になります。
- **AIの自動入力で送るカード画像は、処理のために送信されるだけで、当方のサーバーには保存しません。**
- オンライン対戦のためにアップロードしたカードは、卓を閉じたとき、または卓の期限（最長3時間）が過ぎたあとに自動で削除します。
- ログインした場合のアカウント情報は、アカウントを削除するまで保持します。

## 6. 利用者の選択

| したいこと | 方法 |
|---|---|
| 利用状況の送信を止める | 設定 → プライバシー →「利用状況の共有」をオフ |
| 広告のためのトラッキングを拒否する（iOS） | 初回の確認で拒否、または OS の「設定 → プライバシーとセキュリティ → トラッキング」 |
| 広告の同意を変更する（欧州等） | 設定 → 広告 →「広告のプライバシー設定」 |
| 端末内のデータを消す | アプリ内で個別に削除、またはアプリを削除 |
| サーバー上のアカウントとデータを削除する（ログインしている場合） | 設定 → アカウント →「TCG-T のアカウントを削除」 |
| サーバー上のデータの削除を求める（上記以外） | 下記の連絡先へご連絡ください |

**注意:** ログインせずに使っている間、本アプリのアカウントは匿名で作られるため、**アプリを削除すると、そのアカウントのポイント残高や装飾の権利を復元できません。** Apple または Google でログインしておくと引き継げます。

## 8. 安全管理

- 通信は暗号化（HTTPS）しています。
- サーバー上のデータは、**本人のアカウントからのみ読み取れるよう制限**しています（行単位のアクセス制御）。
- ポイントの増減や権利の付与は、**サーバー側でのみ実行**できるようにしています。
