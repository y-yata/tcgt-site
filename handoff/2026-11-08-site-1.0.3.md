## 目的
TCG-T 1.0.3（2026-11-08 に TestFlight へ。ストアへの提出はこれから）で入る変更を、サイトの日本語・英語のページに書く。公開（push）は Claude Code がストアの公開に合わせて行う。

## 背景（変更の中身。正はアプリのリポジトリ `~/work/TCG-T` の文書）
1. **一人回しの記録**（`docs/solo-records-requirements.md`。旧「中断中」と「履歴」を1つにした）
   - 盤面の ✕ で閉じるとき「保存して終了／保存せずに終了／次から聞かない／戻る」と勝敗（自分の勝ち・相手の勝ち・引き分け・決めない）を選ぶ。勝手には保存しない
   - 保存した記録: **無料 10件・Premium 100件**。満杯のときは Premium の案内か「代わりに消す記録を選ぶ」
   - 「最近の一人回し」: 最後に遊んだ1件を自動で残す（次に遊ぶと入れ替わる）。アプリが落ちたときはホームに「前回の一人回し」
   - 保存した記録から「続きから遊ぶ」「最初から見る」「ここから続ける（分岐）」。閉じるとき「上書き保存／新しく保存／保存しない」
   - タグ: デッキタグ×2（デッキに付けたものが自動で入る）・勝敗×1・自由タグ×2。探す・ゲームで分ける・絞り込み・表示順・並べ替え・まとめて削除
   - オンライン対戦の記録も入る（見るだけ）。設定に「閉じるときに保存するか聞く」
   - Premium をやめて上限を超えた分は消さずに「見るだけ」で残る
2. **デッキ一覧**（`docs/deck-list-requirements.md`）
   - デッキに「デッキタグ」（例: 速攻・コントロール、12文字まで）を付けられる。一覧の名前・デッキタグを押すとその場で直せる
   - 行を押すと詳細。削除はごみ箱でその場で確認。スリーブを付けていれば表紙の後ろに重なって見える
   - デッキタグが2種類以上あれば、タグで絞り込める。デッキの詳細にも「デッキタグ」の行
3. **オンライン卓の「招待を送る」**: 卓を作ったあと、参加コードとストアのリンク入りの文を共有シートで送れる（`src/screen/OnlineRoomHome.tsx`）
4. 直したこと: デッキの詳細から編集して保存すると落ちることがあった／共有の場のゾーンがあるゲームで自分の卓が縮むことがあった／アプリが落ちた直後に一人回しの記録が残らないことがあった
